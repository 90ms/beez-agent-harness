# Security Policy

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/90ms/beez-agent-harness/security/advisories/new)
or contact the maintainer privately through their GitHub profile.

The public issue chooser links to the same private reporting channel. Bug,
performance, and migration forms are not appropriate for suspected security
exposure.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include real secrets or third-party private data.

## Scope

Beez Agent Harness installs instructions and generated project files. Review
skill changes before updating, pin versions for sensitive environments, and
inspect generated diffs before committing them.

Reports are triaged by affected version, reachability, impact, exploitability,
and remediation availability. Coordinate disclosure with the maintainer and do
not publish reproduction details until a fix or explicit disclosure plan exists.
